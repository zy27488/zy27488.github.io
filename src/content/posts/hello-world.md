欢迎来到全新改版的 **从二次元到三W书屋**！

告别了 2022 年的旧版 Hexo 博客，本站现已基于 **Astro 5 + Fuwari** 进行了全面重构与升级。

:::note
**新站点特性一览**
- **极速静态生成**：采用 Astro 孤岛架构，首屏秒开。
- **丝滑页面过渡**：支持 Swup 无刷新平滑切换与动态主题调色盘。
- **全自动云端部署**：基于 GitHub Actions，提交 Markdown 即自动构建发布。
:::

## 快速写作指南

在 `src/content/posts/` 目录下新建 `.md` 文件，或运行以下命令快速生成文章模板：

```bash
pnpm new-post <文章文件名>
```
